# HDL-paradigm-in-Python---Hackaton-2025
The task of the Hackaton was to design SKADA system of the smart thermostat, using Raspberry Pi 3, a temperature sensor and few switches. As SKADA systems often include frontend and network comms, which aren't our domains of interest, we decided to implement a bit of different backend logic to this task - resulting in VHDL paradigm used in Python
